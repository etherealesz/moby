# Scripts

This directory contains various scripts used for automating tasks related to the project. Each script is designed to perform a specific function, such as building the project, running tests, or deploying the application.

## Available Scripts

- `start.sh`: A script to start the application server (for production environment).
- `commands.py`: A Python script to run commands related to the project.
- `alembic`: A directory containing database migration scripts using Alembic.
- `init.sh`: A script to initialize the project environment, such as setting up virtual environments or installing dependencies.
- `init.ps1`: A PowerShell script to initialize the project environment on Windows systems.
